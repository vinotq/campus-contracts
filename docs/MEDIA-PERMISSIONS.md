# Права Медиа КЛКП

`media_review` даёт согласование чужих материалов.
`media_self_review` отдельно разрешает согласование своего материала.
`media_direct_edit` отдельно разрешает прямую правку опубликованных постов.
Дополнительные права не заменяют базовое право согласования.

Права назначаются существующим механизмом значков, как надзорные права.
Новые роли, значки и назначения автоматически не создаются.

Автор материала в заявке на анонсирование определяется назначенным исполнителем.
Статус заявки передаёт `assignee_ref` и `reviewer_ref`. Для выпуска в ленту
АСПиРС проверяет право согласовавшего и, при совпадении с исполнителем,
право самосогласования. Выпуск существующего поста требует прямой правки.
Заявки без этих сведений требуют повторного согласования после обновления.

В решениях `post.reviewed`, `post.edited` и `media.to_feed` идентификатор
редактора обязателен для применения решения. Отсутствие идентификатора
больше не разрешает действие по совместимости.

Порядок выпуска: контракты, Шлюз, КЛКП, АСПиРС.
