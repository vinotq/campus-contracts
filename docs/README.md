## Правило поднятия версии

Версию поднимает тот, кто меняет контракт, — **сразу во всех трёх системах,
одним набором правок**. Порядок выкладки всегда один:

**контракт → Шлюз → отправитель → приёмник.**

Шлюз обязан обновиться первым: он строг намеренно, и его старый пин отбрасывает
сообщение в мёртвую очередь, а обе стороны считают, что всё доехало.

`ENFORCED` — типы, по которым обе стороны уже приведены к контракту. Список
растёт **по одному типу за раз**, вместе с починкой отправителя: включить всё
сразу значит остановить обмен целиком вместо того, чтобы чинить его по частям.
