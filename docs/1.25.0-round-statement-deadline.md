# 1.25.0: срок заявления в обходе

В round.roster.people добавлено необязательное поле statement_until.
Это момент окончания заявления с часовым поясом. Ровно в этот момент
освобождение от отметки заканчивается. Отметка раньше срока не доказывает
присутствие или отсутствие после возврата. Новая отметка ставится вручную.

Поле передаётся только для обычных жильцов. Дежурные и красные комнаты
сохраняют собственное освобождение и не получают этот срок.
Для сданного обхода применяется время сдачи. Старые отправители могут
не передавать поле. Старые строгие получатели отвергнут новое поле.

Перед включением отправки обновить контракт шлюза и КЛКП,
применить миграцию КЛКП f1a7b4c9e532. Затем обновить АСПиРС.
Сначала обновлять принимающие стороны. На прод этот пакет пока не выложен.
