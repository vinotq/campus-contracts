## Самостоятельные публикации Медиа, 1.27.0

`post.created` передаёт согласованный черновик из ЛКП в АСПиРС.

Поля: `local_ref` UUID черновика, `title` до255 знаков, `body_md` до20000,
`images` с обычными ссылками на файлы, `author_ref` и `author`,
`reviewer_ref` и `reviewer`, `decided_at` с часовым поясом.

АСПиРС проверяет автора и согласующего по актуальным правам.
Самосогласование требует отдельного права. Новая публикация получает подпись
«Медиа» и аудиторию всех студентов. Существующая заявка на мероприятие не нужна.

`news.published` и `news.updated` могут содержать `media_draft_ref`.
Это UUID исходного черновика для привязки к каноническому `aspirs_ref`.
Старые публикации это поле не отправляют.

Повтор `local_ref` не создаёт новую публикацию. Недоставленные изображения
оставляют сообщение для ограниченной фоновой повторной обработки.
До получения всех изображений новость не публикуется.

Порядок выпуска: сначала новый контракт, затем шлюз и АСПиРС, затем ЛКП.
