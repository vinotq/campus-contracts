# 1.24.0: окончательное отклонение материалов

`media.request_status_changed.status` и `post.reviewed.verdict` принимают
`rejected`. Для отклонения заявки обязателен непустой `reject_reason`
до 2000 символов. Для публикации причина передаётся в `comment`.
Прежние состояния, возврат `rework` и образцы сообщений совместимы.

Обновлять принимающие АСПиРС и шлюз до включения нового производителя ЛКП.
Старые схемы не принимают новое значение перечисления.

Решение окончательно для текущего материала. История и причина сохраняются.
Отклонённая новая публикация не попадает в ленту. При отклонении новой
редакции уже вышедшей новости её действующая версия остаётся в ленте.
