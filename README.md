# campus-contracts

Контракт обмена между **АСПиРС**, **Шлюзом** и **ЛКП**: конверт, схемы тел,
словари значений и по одному годному образцу на каждый тип.

Человеческая часть — [`docs/CONTRACT.md`](docs/CONTRACT.md). Здесь то же самое кодом.

## Зачем отдельным пакетом

Три системы согласовали список типов сообщений и не согласовали ни одного поля
внутри них. Сообщения доезжали, ложились в очередь и умирали на разборе:
у принимающей стороны `extra="forbid"`, а отказ — одна строка в её журнале.
Снаружи это выглядело как исправный канал и пустой кабинет.

Копия схем в каждом репозитории с тестом на совпадение не годится: она
расходится ровно тогда, когда правку внесли, а тесты не гоняли, — то есть
в том самом случае, от которого защищаемся.

Репозиторий публичный намеренно: здесь нет ни персональных данных, ни ключей,
только имена полей. Приватный потребовал бы токенов в трёх сборках образов
ради того, что и так не тайна.

## Установка

```
campus-contracts @ git+https://github.com/vinotq/campus-contracts@v1.0.0
```

Версия закрепляется тегом в каждой из трёх систем. Поднимает её тот, кто меняет
контракт, — сразу во всех трёх, одним набором правок.

## Как пользоваться

```python
from campus_contracts import Direction, is_enforced, validate

# На отправке: узнать о своей ошибке раньше, чем о ней узнает чужой журнал.
if is_enforced(message_type):
    validate(Direction.DOWNSTREAM, message_type, payload)
```

`ENFORCED` — типы, по которым обе стороны уже приведены к контракту. Список
растёт по одному типу за раз, вместе с починкой отправителя: включить всё сразу
значит остановить обмен целиком вместо того, чтобы чинить его по частям.

Образцы из `campus_contracts.samples` — общие для всех трёх репозиториев.
Отправитель сверяет, что собирает именно это; приёмник — что принимает.

## Правила, которые здесь держатся

- Человек всюду `aspirs_ref`, в обе стороны. Внутренние номера и uuid
  проживающего между контурами не ходят.
- `*_ref` — строка, всегда. `*_at` — момент времени с зоной, `*_date` — дата.
- Перечислимое — только из `campus_contracts.values`.
- Телефон цифрами, почта нижним регистром: для принимающей стороны это ключ
  поиска учётной записи, а не текст для показа.
- Файлы в сообщение не вкладываются, в теле только идентификаторы.
